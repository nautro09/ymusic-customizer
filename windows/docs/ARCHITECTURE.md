# Архитектура и проверка v0.2.0

```text
Официальная Яндекс Музыка → ymusic_mod → mods/ymusic-customizer.js
                                           ├─ Тема и редактор в Shadow DOM
                                           ├─ Селекторы штатной раскладки
                                           ├─ Управление штатным плеером
                                           └─ Опциональный анализ доступного аудиопотока
```

## Renderer

`ymusic_mod` v1.5.0 подключает активные JS-файлы в `music-application://` на `dom-ready`. Windows-установщик самого загрузчика хранит `modloader` и `mods` в `%APPDATA%\YandexMusic`. Имена с префиксом `_` пропускаются при загрузке. Источники — [Windows installer](https://github.com/nersuga/ymusic_mod/blob/v1.5.0/installer/installer.ps1), [modloader/main.js](https://github.com/nersuga/ymusic_mod/blob/v1.5.0/modloader/main.js) и [modloader/features.js](https://github.com/nersuga/ymusic_mod/blob/v1.5.0/modloader/features.js).

Customizer использует один JS-файл и браузерные API. Цвета применяются через переменные приложения и селекторы конкретных зон. Стили редактора изолированы в Shadow DOM. Для проверки оформления рекомендуется штатная тема загрузчика, чтобы исключить конфликт стилей Mica/Acrylic/Glass и правила сторонних модов.

Для Discord установщик добавляет в `modloader/main.js` блок с форматом карточки из `scripts/discord-activity.cjs`. Текущее состояние трека и соединение с Discord по-прежнему предоставляет ymusic_mod. Установщик сохраняет резервную копию, а удаление снимает добавленный блок. При выключенном моде используется карточка загрузчика.

Горячая клавиша — `Ctrl+Shift+Y`, по физической клавише Y. Расширенная панель ищет видимый штатный плеер и доступные кнопки внутри него. Название и обложка берутся из Media Session или текущей панели. Для таймлайна используются штатный ползунок либо доступный HTML-медиаэлемент для отображения прогресса. Команды нажимают штатные кнопки или передают изменение штатному ползунку. Смена DOM после перехода между страницами не сохраняет ссылок на старые кнопки.

Широкий режим меняет только именованные области известной двухколоночной раскладки `DefaultLayout`. При несовпадении шаблона CSS-правило к контейнеру не применяется. В «Моей волне» собственная раскладка сохраняется. Эквалайзер получает сигнал отдельной веткой штатного аудиографа или через `captureStream()`. Анализатор подключается автоматически и повторяет попытки при смене источника или пустом потоке. В ожидании звука редактор показывает состояние подключения. Макет предпросмотра доступен отдельно.

## Совместимость с Next Music

| Возможность | Реализация в Customizer | Источник |
|---|---|---|
| Ручной масштаб | Адаптированы значения основных переменных для масштаба на rem. CSS действует только при включённом ручном режиме. | [noAutoZoom.css, v3.11.1](https://github.com/Web-Next-Music/Next-Music-Client/blob/v3.11.1/src/inject/noAutoZoom.css), MIT. |
| Широкая панель | Использована идея широкой области `playerbar`. Реализация проверяет вычисленную раскладку и сохраняет размеры треков сетки. | [alwaysExpandedPlayer.css, v3.11.1](https://github.com/Web-Next-Music/Next-Music-Client/blob/v3.11.1/src/inject/alwaysExpandedPlayer.css). В README Next Music указывает происхождение возможности из PulseSync Mod. |
| CSS тем | Файлы темы подключаются в renderer после явного подтверждения. Режим приоритета отключает встроенную палитру, чтобы её `!important` не перекрывали CSS темы. Относительные URL не переписываются. | [loadAddons.js, v3.11.1](https://github.com/Web-Next-Music/Next-Music-Client/blob/v3.11.1/src/lib/loadAddons.js). |
| Штатный таймлайн | Используются известные селекторы ползунков. Обработчик передаёт штатному элементу позицию через события браузера. | [listenAlongClient.js, v3.11.1](https://github.com/Web-Next-Music/Next-Music-Client/blob/v3.11.1/src/inject/listenAlongClient.js). |
| Визуализатор | Собственный локальный анализатор на Web Audio API. | [Next Music README](https://github.com/Web-Next-Music/Next-Music-Client#features) указывает Spotifast как источник функции в Next Music. |

Уведомление MIT для параметров масштаба лежит в `licenses/Next-Music-Client-MIT.txt`. Загрузчик распространяется отдельно на условиях его собственной лицензии.

## Профили

Ключ `ymc:theme:v2` содержит версию, палитру, параметры фона, интерфейса и плеера, локальное изображение, пользовательский CSS и до 24 отдельных CSS-файлов в `addonSheets`. Если корректного профиля v2 нет, настройки читаются из `ymc:theme:v1`. Настройки v1 сохраняются для отката. Значения проверяются при чтении и импорте. Удаление устаревшего CSS при импорте выполняется заменой профиля вместо слияния.

## Локальные проверки

```sh
node --check mod/ymusic-customizer.js
node tests/theme-smoke.test.js
npm install --no-save playwright
npx playwright install chromium
node tests/browser-smoke.test.js
```

Переменная `YMC_CHROMIUM` позволяет указать путь к установленному Chromium. Проверки браузера используют локальный HTML-макет. Тест на реальном приложении Windows нужен для оценки обновлений его DOM, IPC и фактического аудиодвижка.
