# Музыка+ · бета

Открой **Магазин и CSS → Плагины → Музыка+ → Скачать и установить**. Справа от магазина появится вкладка **Музыка+**. В ней находятся подключения, проверка обновлений и удаление плагина.

## Что доступно

| Площадка | В Customizer | Где слушать |
| --- | --- | --- |
| YouTube | Поиск музыкальных видео, каналов и плейлистов через YouTube Data API. На странице артиста можно поискать видео по его имени с сортировкой по просмотрам на YouTube. | На YouTube |
| SoundCloud | Поиск треков, профилей и плейлистов через API. | На SoundCloud |
| VK Музыка и Spotify | Переход в поиск площадки с введённым запросом. | На площадке |

1. Для YouTube создай ключ в проекте Google Cloud с включённым YouTube Data API v3. Для SoundCloud зарегистрируй приложение с доступом к API и введи его Client ID и Client Secret. SoundCloud требует Artist Pro для регистрации. Ключи можно отключить в любой момент.
2. Введи запрос в поиске Яндекс Музыки. Открой **Источники**, выбери площадки и нажми **Искать на площадках**. В поддерживаемых вкладках появятся подписанные блоки рядом со штатными результатами. Во вкладках без подходящего типа выдачи будут ссылки на поиск у источника.
3. Нажми на название находки, чтобы открыть её на площадке. Метка источника стоит перед сердечком. Сердечко добавляет трек в **Свою волну** текущего сеанса. Значок скачанного трека в строках Яндекс Музыки остаётся на месте.
4. На главной открой **Своя волна**. Можно записать любимых артистов или названия треков, по очереди искать их на выбранной площадке и подбирать из сохранённых находок. Волна учитывает эти предпочтения, чередует артистов по мере наличия и пропускает уже предложенные треки за сеанс.

В бете воспроизведение, аккаунт, географические ограничения и доступность контента контролирует сама площадка. «Своя волна» ведёт отдельную подборку из находок, добавленных в текущем сеансе. Яндекс Музыка продолжает вести свою волну и очередь.

## Данные и нагрузка

Ключи, токены и результаты поиска хранятся в памяти текущего сеанса. При нажатии **Искать на площадках** запрос получает выбранная площадка с подключённым API. При переходе во внешний поиск запрос передаётся через адрес страницы площадки. Из пользовательских данных между запусками сохраняются выбранные источники и введённые вручную предпочтения в локальном профиле Customizer.

Поиск запускается кнопкой. Повторный запрос использует короткий сеансовый кеш, а запрос к ушедшему экрану отменяется. В скрытом окне Customizer приостанавливает периодическое обновление оформления и анимацию фоновых узоров. Штатный плеер и загрузки Яндекс Музыки работают своим обычным путём.

## Обновления

Пакет плагина находится в [релизе Music Plus Beta](https://github.com/nautro09/ymusic-customizer/releases/tag/music-plus-beta). Установщик проверяет подпись проекта, версию Customizer и формат манифеста. Манифест содержит версию и список доступных адаптеров. Доверенный код адаптеров входит в установщики Customizer и обновляется вместе с ними.

Для выпуска нового манифеста увеличь версию в `manifest.json`, создай подписанный файл командой `python3 scripts/sign-music-plus.py /путь/к/ключу /путь/к/music-plus.json` из корня проекта и прикрепи его к релизу плагина. Ключ подписи хранится вне Git.
